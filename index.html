Updating

Run the new Windows installer, or install the new Android ARM64 APK over your release installation. Existing data stays in place. Android asks for your approval; updates are never silently installed.

If Android reports a signing conflict, do not uninstall without exporting your data first. Debug previews use a different signing identity.

Personal-use preview

Windows installers are unsigned. Do not disable security protections to install Grindset. Background operation can be interrupted by permissions, force-stop and OS restrictions. Physical Android reliability and visible Windows completion alerts remain unverified.

Tracking is opt-in. Grindset records app/domain identifiers and confirmed usage timestamps, not page titles, full browsing URLs, screen contents or keystrokes. Optional account sync sends identifiers and timestamps to the app's Supabase project. Saved exports contain private activity data. This is not a store-reviewed release or a promise of continuous enforcement.

Only the download files and this small website are public. App source remains private. This website has no analytics, cookies or account storage.
